# サンプルデータの出所と区分

**ここにあるものはすべて合成デモデータです。** 画像は AI 生成で、実在の写真・投稿ではありません。投稿者名（`@sample_*`）、本文、投稿日時も架空です。実在の素材（実際の SNS 投稿・撮影写真）は含みません。

| 区分 | 場所 | 用途 | 画面への表示 |
|---|---|---|---|
| デモ | `samples/samples.json` と `samples/*.jpg` | 画面のサンプル投稿（各カードに「合成デモデータ」と表示） | 表示する・サーバーから配信する |
| 異常系の回帰 | `samples/edge/cases.json` と `samples/edge/*.jpg` | 未来日時・過去の写真・EXIF・日時不明・園内の東西・公園中心・矛盾・場所なし・重複の確認 | 表示しない・配信しない |

## デモの 3 つのシナリオ
- (a) 根拠が十分 → 地図に反映：`s3`（高尾山薬王院・色づき始め）。周囲 4km に同じ種類の掲載がないため、新しいスポットとして追加。
- (b) 場所が曖昧 → 人が確認：`s6`（いろは坂）。掲載は区域「明智平」のスポットだが、投稿には区域が書かれていないため自動では統合せず、確認ボタンを表示。写真と本文の矛盾も検出。
- (c) 過去の写真 → 反映しない：`s8`（「去年の11月に撮った」東福寺・通天橋）。区域スポットには照合できるが、現在の段階は変えずに履歴だけに残す。
- `s1` `s2` `s4` は彼岸花の補足用です（シーズンを過ぎた投稿なので、「投稿から N 日経過」と表示されます）。

## 回帰テスト用データ
- `s5_future` / `s7_future` は未来日時を扱う異常系フィクスチャです。日付は固定値であり、実在する観測日時ではありません。
- `s8` の合成画像には `s5_momiji_peak.jpg` を使用します。
- 初期データの座標の出典と限界は `docs/evidence/seed-verification-2026-10-22.md` を参照してください。
